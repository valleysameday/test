## 🌄 About RCT‑X  
RCT‑X is a fast, friendly, mobile‑first marketplace designed specifically for the Rhondda community.  
It focuses on simplicity, speed, and a warm local feel — giving residents a place to buy, sell, and connect without the noise of national platforms.

---

## ✨ Features  
- 🏡 Local‑first marketplace for Rhondda  
- 📱 Mobile‑first UI with smooth animations  
- 🖼️ Smart image gallery with optional ad slides  
- 💬 Real‑time messaging between buyers & sellers  
- 🔔 Seller notifications  
- 📊 Admin analytics dashboard  
- 🛍️ Business plans & instant upgrades  
- 🔒 Secure Firebase Authentication  
- ☁️ Firestore + Storage for posts, images, and messaging  

---

## 🚀 Tech Stack  
- **JavaScript (ES6 modules)**
